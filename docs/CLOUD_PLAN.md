# x86_64 评测环境候选

核验日期：2026-10-22。尚未创建资源、注册账号或产生云费用。分配上限仍为 2 USD，计入总预算 10 USD；目前没有已确认可以在此额度内完成构建与评测的方案。

## 首选：已有或短租 x86_64 Linux 主机

沿用原方案：至少 8 个 CPU 核/明确标注的 vCPU、32 GB 内存、200 GB 磁盘，Docker 可用；单并发固定 dev 冒烟，不需要 GPU。已有主机也应记录归属项目的实际计费，不假定免费。

在确定服务商/区域之前不编造小时报价。下单前要核对 CPU 架构、含税价、磁盘和 IP 费用、最小计费单位，并给构建失败留出余量。例如 [Hetzner 官方计费说明](https://docs.hetzner.com/cloud/billing/faq/) 明确关机仍计费、按小时向上取整，要删除资源才停止对应计费；本轮尚无该服务商可用账号和确定报价。

## 候选：官方 harness 的 Modal 路径

[SWE-bench 官方指南](https://www.swebench.com/SWE-bench/guides/evaluation/) 提供 Modal 评测入口，因此可以作为判分候选，但不能据此认定自研 Agent 的 Docker 沙箱也能无修改迁移。必须核对镜像、架构、禁网和资源限制，保持 Agent 与隐藏测试隔离。

[Modal 官方价格](https://modal.com/pricing) 在核验日列出的 Sandbox CPU 为 0.00003942 USD/物理核/秒、内存为 0.00000667 USD/GiB/秒；每物理核注明等价 2 vCPU。按 4 物理核（8 vCPU）和 32 GiB 的纯运行价计算约 1.336032 USD/小时。这是价格公式外推，不是本项目实测；尚未包含构建、存储、网络或失败重试，也不代表能够满足所有任务资源需求。

Starter 公布每月 30 USD credits，但账号资格与剩余额度未核验，不能计作已经获得的免费资源。Sandbox 费率不同于普通函数资源费率，不能误用较低的函数报价。

## 执行前条件

1. 确定用户已有账号或主机、资源规格与当时实付价格；不索取聊天中的密码或密钥。
2. 在创建前对云总费用预留，设置明确寿命、单并发和清理机制；账户优惠独立记录。
3. 先构建并验证固定 dev 实例 sympy__sympy-22840。若构建超时、镜像不兼容或无法满足 2 USD 分配，停止该环境，不悄悄扩预算或替换更易任务。
4. 全程使用官方 harness 判分；保留原始失败。未找到可行环境时按用户已确认方案交付代码/离线验证，成功率及沙箱实测开销保持未测。
