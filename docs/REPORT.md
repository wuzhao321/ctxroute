# ctxroute 阶段报告：代码实现与本地联调

更新：2026-10-23。本报告描述已实现的工程能力和现有证据，不是 SWE-bench 实验结果。

## 方法与实现

目标仍是比较结构化上下文压缩、步骤级模型路由对含缓存成本、延迟和任务成功率的影响。划分、假设和预算规则见 PREREG.md；正式 test 暂缓，当前只允许固定 dev pilot。A0 为原生文本外部参考；A1 是内部对照，A2/A3/A4 分别加入压缩、路由与二者联合。A5 已有代码但本轮 pilot 未纳入。

核心实现包括任务循环、四分区上下文、批量压缩、证据化历史观察、规则路由、预算预留、MCP/Docker 适配、不可变计划、预测导出及统计分析。结构化记忆和分阶段复现分别见 STRUCTURED_MEMORY.md、REPRODUCE.md。A0 与 A1 的提示和动作接口不同，不能将二者差异直接归因于压缩或路由。
