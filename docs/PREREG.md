## 目标与假设

H1：成功与轨迹长度/上下文长度相关，仅观察性诊断，不预设线性或因果。
H2：结构化压缩降低含缓存成本且 pass@1 非劣。
H3：步骤级路由降低成本和延迟且 pass@1 非劣。
非劣边界 δ=0.05，配对成功率差 95% CI 下界须至少为 -0.05。少量 dev pilot 不支持总体非劣结论，不将不显著写成等效。

本轮主要目的为验证端到端可运行性和测量费用；H1–H3 仅标注 dev 探索性。正式 test 全部未测。

## 实验臂和顺序

A0=mini-swe-agent 强模型；A1=ctxroute 强模型，无压缩/路由；A2=A1+压缩；A3=A1+路由；A4=A1+压缩+路由。A5 仅廉价模型、A6 多 Agent 和 A7 外部 harness 本轮不运行。

每实例所有臂同一环境、任务描述、步数上限与超时，单 replicate 标识 seed=20261022；供应商若不支持 seed，不声称调用确定性。按候选顺序，每实例 A0→A1→A2→A3→A4。时间/缓存次序偏差作为局限，不做未计费的预热请求。

A0/A1 一致性先在离线固定响应 fixture 检查动作解析、终止及补丁提取；真实成功结果单独报告，小样本不宣称统计等价。A2-A1、A3-A1 为主配对，A4-A1 为联合探索性；recall 差异单列效度威胁。

算法建议沿原规格 K=6、70%/90% 压缩阈值、strong 锁定 5 步；具体上下文预算、提示、SDK、思考参数及镜像在实现后、付费前写入配置并提交。缺项则不运行。模型 ID/价格快照在调用前再次核验。

## 预算及停止

- 总额 10 USD，8 USD 暂停；达到阈值前按最坏预留拦截。日历最多 3 天，不做模型训练。
- 初次 API 连通预留最多 0.10 USD；云计算、磁盘和流量合计预留最多 2 USD。只有能核验上界并可及时销毁的方案才创建资源。尚无服务商报价，不假定必然可行。
- 每任务每臂 API 上限 0.20 USD，包含压缩、重试及辅助调用；每实例五臂最多 1 USD。最多五个完整组合，不因成功率扩样。
- 每臂最多 50 步、墙钟最多 10 分钟，单命令默认 30 秒；可能因美元限制提前终止，报告终止比例。
- 按输入和最大输出、高峰价计算保守预留，不用平均 token 作硬上界。已用+未结算预留+下一完整组合上界达到 8 USD，则不启动组合；不能根据中途结果改变候选顺序。
- 云费用无法限制、构建超时或预算不足则只交付实现和离线验证，benchmark 指标未测，不静默降低门槛。
- 未知 usage 保留预留；费用超预留记录实际、锁停。两次尝试未解决即停。每阶段等待用户“继续”。

## 缺失、重跑与统计

基础设施失败、空补丁、格式错误、预算终止分别记录。成功率分母为该臂已启动实例，非成功项不从分母删除，另列实际判分数量。未启动任务不计作模型失败，但报告数量；不完整配对不用于主配对估计，保留单臂数据并列出排除原因。

API 失败最多一次额外重试，费用/延迟计入；harness 基础设施错误最多重跑一次，新 run_id 引用首跑且不覆盖，报告同时保留首跑和重跑口径。格式纠错最多一次且计入步骤和费用。

优先逐实例原始数据。至少 2 个完整配对才给实例级配对 bootstrap 95% CI（seed=20261022，10,000 次）；二元成功给精确双侧 McNemar，零不一致对时 p=1。仅供探索，不推断总体收益。P95 连同样本数和逐项延迟报告，小样本下不稳定。

API 成本含命中/未命中输入、输出、压缩及重试，云总费用另列。配对成本/延迟比值的中位数和 CI 仅作诊断；零分母标为不可定义，报告绝对差，不加任意 epsilon。多 seed 不在本轮范围。
